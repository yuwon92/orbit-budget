# Orbit — 오늘의 예산

항목별 예산을 정해두고 오늘 쓸 수 있는 금액을 알려주는 개인 예산 웹앱. 서버 없음, 로컬 저장.

## 기능

- **홈** — 오늘 예산 / 남은 금액을 카테고리별 몫과 자유 몫으로 분해(주 한도면 주 예산, 요일 지정이면 그날 몫), 주·일 횟수 한도 표시, 퀵 슬롯 구슬(교통은 한 번 탭에 편도 요금, 횟수는 단가 프리필, 그 외는 카테고리만 지정된 시트), 카드 ⋯ 메뉴로 홈 요약·퀵 슬롯 표시 토글, 카테고리별 진행률, 오늘 내역
- **달력** — 날짜별 지출·수입·예정 거래, 날짜 선택 시 상세
- **거래 내역** — 날짜별 그룹, 메모·카테고리 검색, 종류·카테고리 필터, 수정·삭제
- **설정** — 카테고리 관리, 반복 거래, 예비비, CSV 내보내기, 라이트/다크 테마
- **예산 계산 도구** — 월 예산을 횟수(한 번에 얼마 × 주 몇 회), 교통(편도 × 왕복), 구독 합계로 산출. 요일 지정 시 그 달 실제 요일 수 반영, 금액은 한 번 단가의 배수로 반올림, 달·반복 거래 변경 시 자동 갱신
- **반복 거래** — 매달 정해진 날짜에 예정 거래 자동 생성, 월말 날짜 보정
- **PWA** — 홈 화면 추가로 앱처럼 실행

계산식 ([`src/lib/budget.ts`](src/lib/budget.ts))

```
가용액    = 이번 달 총수입 − 이미 발생한 지출(오늘 이전)
오늘 예산 = (가용액 − 남은 기간의 예정 지출 − 예비비) ÷ 남은 일수
남은 금액 = 오늘 예산 − 오늘 이미 쓴 금액
```

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 검사 + 빌드
npm run verify   # 계산 로직 검산
```

## 주의사항

- 데이터는 브라우저 IndexedDB에만 저장. 기기 간 동기화 없음 (PC와 폰 별개)
- 브라우저 데이터 삭제 시 함께 소실
- iOS 사파리는 7일 미방문 시 저장소 삭제. 홈 화면 추가하면 제외
- 백업 수단은 설정 → CSV 내보내기뿐. 주기적 백업 권장
- 금액 계산은 정수, 나눗셈은 내림 처리
